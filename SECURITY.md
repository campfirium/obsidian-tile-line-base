# Security Policy

## Supported Versions

TileLineBase is currently in active development as an Obsidian plugin. Security reports should target the latest public release and the latest commit on the `dev` branch unless a release note states otherwise.

## Reporting a Vulnerability

Please do not open a public issue for a suspected security vulnerability.

Use GitHub's private vulnerability reporting flow for this repository so the details can be reviewed and fixed before public disclosure:

https://github.com/campfirium/obsidian-tile-line-base/security/advisories/new

When reporting, include:

- A clear description of the issue.
- Steps to reproduce or a minimal proof of concept.
- The affected surface, such as Markdown parsing, table rendering, link handling, import/export, or Obsidian plugin integration.
- Any known impact or workaround.

We will review valid reports privately, coordinate a fix, and publish security details only after the issue is resolved or otherwise safe to disclose.
